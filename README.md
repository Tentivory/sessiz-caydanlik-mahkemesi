# SESSİZ ÇAYDANLIK MAHKEMESİ

## Resmiyet Bildirisi

Bu depo, insanlığın çay demleme suçlarını yargılamak üzere kurulmuş **uluslararası sessiz mahkemedir**.
Yargıç konuşmaz. Çaydanlık ıslık çalmaz. Karar ekrana düşer.

> "Dem fazla beklerse tarih de bekler."  
> — 7. Daire, 3. Bardak, içtihat no: 1342

## Ne Yapıyor?

`mahkeme.py` çalıştığında:
1. Sana demlenme süresini sorar.
2. Bardak sayısını sorar.
3. Şeker durumunu sorar (siyasi değil, tatlılık meselesi).
4. Anayasa niteliğindeki **Dem Kanunu**'na göre hüküm verir.
5. Gerekirse seni sürgüne (mutfağın diğer köşesine) gönderir.

Gerçekten çalışır. Şaka olan kısım hayatın kendisidir.

## Kurulum

```bash
python3 mahkeme.py
```

Bağımlılık yoktur. Sadece vicdan ve bir tutam küstahkârlık yeter.

## Anayasa (kısa)

- 0-2 dakika: **ham** — suç: aceleciliğe teşvik.
- 3-6 dakika: **kanuni dem** — beraat.
- 7-12 dakika: **ağır dem** — para cezası yerine kınama.
- 13+ dakika: **tarihi eser** — çay artık içilmez, müzeye kalkar.
